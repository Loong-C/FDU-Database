## 3. 当前运行阻塞

当前后端默认按 MySQL 连接，配置来源为 `backend/.env`。

在本机默认配置 `root` + 空密码下，Django 在检查数据库一致性时返回：

```text
Access denied for user 'root'@'localhost' (using password: NO)
```

这说明：
- 本机存在可访问的 MySQL 服务
- 但当前仓库未提供可用的 MySQL 账号密码
- 因此 `migrate`、`bootstrap_business_db --seed --views`、`manage.py test` 的最终联调验证，需要补充正确凭据后执行

## 4. 凭据补齐后的验证命令

在 `backend/.env` 中填入正确的 `DB_HOST / DB_PORT / DB_NAME / DB_USER / DB_PASSWORD` 后，按以下顺序验证：

```powershell
cd backend
..\.venv\Scripts\python manage.py migrate
..\.venv\Scripts\python manage.py bootstrap_business_db --seed --views
..\.venv\Scripts\python manage.py seed_demo_users
..\.venv\Scripts\python manage.py test common.tests
```

注意：
- 上述命令在实际终端中应写成 `..\.venv\Scripts\python ...`
- `bootstrap_business_db` 会按 SQL 脚本创建数据库、建表、导入样例数据、创建统计视图
