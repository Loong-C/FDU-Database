## 3. 联调中发现并修复的问题

### 3.1 数据库初始化顺序问题

现象：
- 在全新环境中直接运行 `python manage.py migrate` 会报错：

```text
Unknown database 'online_bookstore_db'
```

原因：
- Django 迁移依赖数据库已存在
- 业务库应先通过 `bootstrap_business_db` 创建，再执行 `migrate`

修正：
- 已将运行文档中的推荐顺序改为先 `bootstrap_business_db`，后 `migrate`

### 3.2 MySQL 时区表导致的日期过滤问题

现象：
- 统计接口测试最初失败，`/api/v1/analytics/stores/daily` 在存在样例数据时返回空列表

根因：
- Django 在 MySQL 上对 `sale_time__date` 生成了 `DATE(CONVERT_TZ(...))`
- 当前 MySQL 实例未加载时区表，`CONVERT_TZ` 返回 `NULL`
- 导致基于日期的过滤条件全部失效

修正：
- 已将销售列表与 4 组统计接口的日期过滤改为“本地日期边界 -> datetime 范围过滤”
- 不再依赖 MySQL 时区表
