# Bookstore 用户手册

## 1. 启动与登录

1. 按 README 初始化 MySQL、后端和前端。
2. 浏览器打开前端开发地址，默认 `http://127.0.0.1:5173`。
3. 使用演示账号登录：

| 用户名 | 密码 | 角色 |
|---|---|---|
| `admin` | `Admin123!` | 管理员 |
| `operator` | `Operator123!` | 操作员 |
| `viewer` | `Viewer123!` | 查询用户 |

## 2. 常用功能

- 数据总览：查看今日销售额、订单数、会员消费和库存预警。
- 销售分析：按门店、商品、会员、分类查看统计结果，可导出当前视图。
- 商品/图书管理：维护基础信息、供货关系，并选择门店写入初始库存和安全库存。
- 门店库存：按门店、商品、预警状态筛选库存；管理员可调整当前库存和安全库存。
- 销售订单：查询销售记录；新开销售单时先选门店，再添加该门店有库存的商品。
- 采购单：选择供应商、门店和商品明细，创建采购记录。
- 入库单：选择采购单并录入到货明细；状态为“已审核”时，系统会增加对应门店库存。

## 3. 推荐演示链路

1. 使用 `admin` 登录，进入“商品管理”，新增普通商品或图书，选择门店并填写初始库存、安全库存。
2. 进入“门店库存”，筛选该商品，调整安全库存到高于或等于当前库存，观察预警状态。
3. 进入“新开销售单”，先选择门店，再搜索并加入商品，提交后查看销售单详情。
4. 回到“门店库存”，确认该门店商品库存已扣减。
5. 进入“采购单”，创建一张包含该商品的采购单。
6. 进入“入库单”，选择刚才的采购单，状态选择“已审核”并保存。
7. 再回到“门店库存”和“数据总览”，确认库存增加、预警数量变化。

## 4. 权限说明

- `admin`：可维护基础资料、商品图书、库存、采购入库、销售和用户。
- `operator`：可查看基础资料，维护客户、会员、销售、采购和入库。
- `viewer`：仅可访问数据总览和销售分析。

运行时权限由 Django 自定义用户 `accounts.User.role` 控制；SQL 中的 `system_user`、`role`、`permission` 等表作为数据库设计层 RBAC 模型保留。
