# 网上综合书店销售数据库项目
## 表结构草案（3NF，与 PPTX 对齐版）

> 文档用途：作为 `sql/create_tables.sql` 的设计依据。
> 对齐来源：`pre/网上综合书店销售数据库_展示(6).pptx` 第 21、42-51 页。

---

## 1. 设计原则

- 满足第三范式（3NF），避免把库存等可变业务事实冗余到商品基础表。
- 主键统一使用 `xxx_id`，共享主键用于 `book`、`member`。
- 多对多关系通过中间表表达，中间表优先使用复合主键。
- 明确 `NOT NULL`、`UNIQUE`、`CHECK`、`FOREIGN KEY` 约束。
- 库存按 `store_id + product_id` 维护，支撑连锁门店场景。

## 3. 核心表结构

### 3.1 `store`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `store_id` | BIGINT | PK | 门店编号 |
| `store_name` | VARCHAR(100) | NOT NULL, UNIQUE | 门店名称 |
| `city` | VARCHAR(50) | NOT NULL | 所在城市 |
| `address` | VARCHAR(255) | NOT NULL | 地址 |
| `phone` | VARCHAR(30) | UNIQUE | 电话 |
| `manager_name` | VARCHAR(50) |  | 负责人 |
| `created_at` | DATETIME | NOT NULL | 创建时间 |

### 3.2 `supplier`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `supplier_id` | BIGINT | PK | 供应商编号 |
| `supplier_name` | VARCHAR(100) | NOT NULL, UNIQUE | 供应商名称 |
| `contact_name` | VARCHAR(50) |  | 联系人 |
| `phone` | VARCHAR(30) |  | 电话 |
| `email` | VARCHAR(100) | UNIQUE | 邮箱 |
| `status` | VARCHAR(20) | NOT NULL, CHECK | `active` / `inactive` |

### 3.3 `category`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `category_id` | BIGINT | PK | 分类编号 |
| `category_name` | VARCHAR(100) | NOT NULL, UNIQUE | 分类名称 |
| `parent_category_id` | BIGINT | FK -> `category.category_id` | 父分类，可空 |

### 3.4 `product`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `product_id` | BIGINT | PK | 商品编号 |
| `product_name` | VARCHAR(200) | NOT NULL | 商品名称 |
| `category_id` | BIGINT | NOT NULL, FK | 商品分类 |
| `unit` | VARCHAR(20) | NOT NULL | 计量单位 |
| `unit_price` | DECIMAL(10,2) | NOT NULL, CHECK > 0 | 零售价 |
| `cost_price` | DECIMAL(10,2) | CHECK >= 0 | 成本价 |
| `barcode` | VARCHAR(50) | UNIQUE | 商品条码 |
| `status` | VARCHAR(20) | NOT NULL, CHECK | `onsale` / `offsale` / `discontinued` |
| `created_at` | DATETIME | NOT NULL | 创建时间 |

说明：`product` 不保存库存，库存统一放入 `inventory`。

### 3.5 `book`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `product_id` | BIGINT | PK, FK -> `product.product_id` | 图书商品编号，共享主键 |
| `isbn` | VARCHAR(20) | NOT NULL, UNIQUE | ISBN |
| `publisher_id` | BIGINT | NOT NULL, FK | 出版社 |
| `publish_date` | DATE |  | 出版日期 |
| `edition` | VARCHAR(20) |  | 版次 |
| `language` | VARCHAR(30) |  | 语言 |
| `page_count` | INT | CHECK > 0 | 页数 |

### 3.6 图书辅助表

| 表名 | 关键字段与约束 | 说明 |
|---|---|---|
| `publisher` | `publisher_id` PK，`publisher_name` UNIQUE | 出版主体 |
| `author` | `author_id` PK，`author_name` NOT NULL | 作者 |
| `translator` | `translator_id` PK，`translator_name` NOT NULL | 译者 |
| `book_author` | PK(`product_id`, `author_id`)，外键到 `book` 和 `author` | 多作者关系 |
| `book_translator` | PK(`product_id`, `translator_id`)，外键到 `book` 和 `translator` | 多译者关系 |

### 3.7 客户与会员

| 表名 | 关键字段与约束 | 说明 |
|---|---|---|
| `customer` | `customer_id` PK，`phone` UNIQUE，`email` UNIQUE，`status` CHECK | 客户基础信息 |
| `member` | `customer_id` PK/FK，`member_no` UNIQUE，`points >= 0` | 会员子表 |

### 3.8 销售

| 表名 | 关键字段与约束 | 说明 |
|---|---|---|
| `sale` | `sale_id` PK，`store_id` FK，`customer_id` 可空，金额非负 | 销售主单 |
| `sale_item` | PK(`sale_id`, `line_no`)，`product_id` FK，`quantity > 0`，`line_amount = quantity * unit_price` | 销售明细 |

## 4. 权限控制表

| 表名 | 字段 | 约束与说明 |
|---|---|---|
| `system_user` | `user_id`, `username`, `password_hash`, `real_name`, `phone`, `email`, `status`, `created_at` | `username` 唯一；不存明文密码；`status` 为 `active` / `disabled` |

| `permission` | `permission_id`, `permission_code`, `permission_name`, `module_name` | `permission_code` 唯一 |
| `user_role` | `user_id`, `role_id` | 复合主键，外键到用户和角色 |
| `role_permission` | `role_id`, `permission_id` | 复合主键，外键到角色和权限 |

## 5. 采购入库与库存表

### 5.1 `purchase_order`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `purchase_order_id` | BIGINT | PK | 采购单编号 |
| `supplier_id` | BIGINT | NOT NULL, FK | 供应商 |
| `store_id` | BIGINT | NOT NULL, FK | 采购门店 |
| `created_by` | BIGINT | NOT NULL, FK -> `system_user.user_id` | 创建用户 |
| `order_time` | DATETIME | NOT NULL | 下单时间 |

| `total_amount` | DECIMAL(12,2) | NOT NULL, CHECK >= 0 | 采购总额 |

### 5.2 `purchase_order_item`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `purchase_order_id` | BIGINT | PK(复合), FK | 采购单 |
| `line_no` | INT | PK(复合), CHECK > 0 | 行号 |
| `product_id` | BIGINT | NOT NULL, FK | 商品 |
| `quantity` | INT | NOT NULL, CHECK > 0 | 采购数量 |
| `purchase_price` | DECIMAL(10,2) | NOT NULL, CHECK > 0 | 采购单价 |
| `line_amount` | DECIMAL(12,2) | NOT NULL, CHECK | 行金额 |

### 5.3 `stock_in`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `stock_in_id` | BIGINT | PK | 入库单编号 |
| `purchase_order_id` | BIGINT | NOT NULL, FK | 来源采购单 |
| `store_id` | BIGINT | NOT NULL, FK | 入库门店 |
| `operator_id` | BIGINT | NOT NULL, FK -> `system_user.user_id` | 操作用户 |
| `inbound_time` | DATETIME | NOT NULL | 入库时间 |
| `status` | VARCHAR(20) | NOT NULL, CHECK | `pending` / `approved` / `rejected` |

### 5.4 `stock_in_item`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `stock_in_id` | BIGINT | PK(复合), FK | 入库单 |
| `line_no` | INT | PK(复合), CHECK > 0 | 行号 |
| `product_id` | BIGINT | NOT NULL, FK | 商品 |
| `quantity` | INT | NOT NULL, CHECK > 0 | 入库数量 |
| `unit_cost` | DECIMAL(10,2) | NOT NULL, CHECK > 0 | 入库成本 |
| `line_amount` | DECIMAL(12,2) | NOT NULL, CHECK | 行金额 |

### 5.5 `inventory`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `store_id` | BIGINT | PK(复合), FK -> `store.store_id` | 门店 |
| `product_id` | BIGINT | PK(复合), FK -> `product.product_id` | 商品 |
| `stock_qty` | INT | NOT NULL, DEFAULT 0, CHECK >= 0 | 当前库存 |
| `safety_stock_qty` | INT | NOT NULL, DEFAULT 0, CHECK >= 0 | 安全库存 |
| `updated_at` | DATETIME | NOT NULL | 更新时间 |

## 6. 约束汇总

| 约束类型 | 设计策略 |
|---|---|
| 主键约束 | 每表设置主键；共享主键用于 `book`、`member`；中间表使用复合主键 |
| 外键约束 | 权限、采购、入库、销售、库存全部外键化 |
| 唯一约束 | ISBN、会员编号、用户名、权限编码、门店名、分类名等关键字段唯一 |
| 非空约束 | 必填业务字段统一 `NOT NULL`；`sale.customer_id` 可空支持散客 |
| 检查约束 | 价格/数量为正，库存/安全库存/金额/积分非负，金额等式和状态枚举校验 |

---

## 7. 阶段结论

本表结构草案已覆盖 PPTX 展示中的 25 张表，并修正原仓库中把库存放在 `product.stock_qty` 的设计偏差。后续 SQL、后端库存逻辑和 API 文档应以 `inventory` 为门店库存唯一来源。
