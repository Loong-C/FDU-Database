# 数据库文档修正说明

> 本说明记录本次按照 `pre/网上综合书店销售数据库_展示(6).pptx` 对数据库相关材料做出的主要调整。

---

## 1. 修正背景

原仓库中的数据库设计已经覆盖门店、供应商、商品、图书、客户、会员、销售和统计视图等核心内容，但与 PPTX 展示相比仍缺少三类内容：

- 权限控制：`system_user`、`role`、`permission`、`user_role`、`role_permission`
- 采购入库：`purchase_order`、`purchase_order_item`、`stock_in`、`stock_in_item`
- 门店库存：`inventory`

同时，原设计把库存放在 `product.stock_qty`，而 PPTX 明确要求库存按 `store_id + product_id` 放在 `inventory`。

---

## 2. SQL 修正内容

- `create_tables.sql` 扩展为 25 张表。
- 从 `product` 表移除 `stock_qty` 字段。
- 新增 `inventory` 表，使用 `(store_id, product_id)` 复合主键。
- 新增权限控制、采购单、采购明细、入库单、入库明细表。
- `sql/data/*.csv` 保存权限样例、采购入库样例和门店库存样例，由后端初始化命令统一导入。
- `views_or_reports.sql` 新增 `v_inventory_warning` 和 `v_store_inventory_summary`。

---

## 3. 文档修正内容

- `需求分析.md` 补充权限控制、采购入库、门店库存三类业务范围。
- `ER图.md` 新增权限、采购入库、库存与销售关系子图。
- `表结构草案.md` 按 25 张表重写总览与关键字段说明。
- `SQL脚本文件说明.md` 更新执行后验证方式和视图清单。
- 新增 `PPTX数据库一致性修正报告.md`，集中说明差异、修正和验证建议。

---

## 4. 当前状态结论

数据库设计材料已与 PPTX 中的表清单、关系基数、库存设计和附录关系模式保持一致。后端需要同步将库存读写从 `product.stock_qty` 改为 `inventory.stock_qty`。
